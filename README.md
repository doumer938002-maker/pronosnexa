# PronoNexa (site d'information hippique)

Site statique (GitHub Pages). Données d'exemple dans `data/pronos.json`.
Le site est en `noindex` tant que les vraies données et les mentions légales ne sont pas complétées.
Pour l'ouvrir aux moteurs de recherche : retirer `noindex,nofollow` des pages et le `Disallow` de `robots.txt`.
